# @six5536/smllm-linux-arm64

Prebuilt `smllm` binary for **linux-arm64**. This is an internal artifact of
[`smllm`](https://www.npmjs.com/package/smllm), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `smllm` instead.
