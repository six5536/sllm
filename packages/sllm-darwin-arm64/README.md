# @six5536/sllm-darwin-arm64

Prebuilt `sllm` binary for **darwin-arm64** (macOS, Apple silicon). This is an
internal artifact of [`sllm`](https://www.npmjs.com/package/sllm), which
installs it automatically as an optional dependency on a matching machine. Don't
depend on it directly; install `sllm` instead.
