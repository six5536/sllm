# @six5536/smllm-darwin-x64

Prebuilt `smllm` binary for **darwin-x64** (macOS, Intel). This is an internal
artifact of [`smllm`](https://www.npmjs.com/package/smllm), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `smllm` instead.
