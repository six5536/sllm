# @six5536/smllm-darwin-arm64

Prebuilt `smllm` binary for **darwin-arm64** (macOS, Apple silicon). This is an
internal artifact of [`smllm`](https://www.npmjs.com/package/smllm), which
installs it automatically as an optional dependency on a matching machine. Don't
depend on it directly; install `smllm` instead.
