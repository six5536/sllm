# @six5536/sllm-darwin-x64

Prebuilt `sllm` binary for **darwin-x64** (macOS, Intel). This is an internal
artifact of [`sllm`](https://www.npmjs.com/package/sllm), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `sllm` instead.
