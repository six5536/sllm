# @six5536/sllm-linux-arm64

Prebuilt `sllm` binary for **linux-arm64**. This is an internal artifact of
[`sllm`](https://www.npmjs.com/package/sllm), which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `sllm` instead.
