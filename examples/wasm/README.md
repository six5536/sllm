# smllm-wasm example

An agent loop over [`smllm-wasm`](../../packages/smllm-wasm), with a scripted
model that answers instantly (a stand-in for a model that answers in
milliseconds), so it can show smllm's own time per turn.

- `agent-loop.ts`: the loop, with web-standard APIs only, so it runs in a browser
  as in Node. It gives the model `engine.tool()`, passes each tool call to
  `engine.callTool()`, and asks `engine.stop()` when the model wants to stop.
- `node.ts`: the loop in Node, with `smllm-wasm/node`'s `nodeHost` (real `command`
  guards and actions) and `nodeFileStorage`. It runs twice on one storage folder:
  the second run is a new engine that continues the paused note. It checks what
  should happen, and prints smllm's time per turn apart from storage and commands.
- `note.smllm.yaml`: the machine (write a note, a command checks it, another files
  it); `machines.json` is its `smllm compile` output, regenerated by
  `npm run build:wasm`.

```sh
npm run build:wasm      # the wasm and the package
npm run test:example    # type-check, then run node.ts
```

In a browser, import `init` and `Engine` from `smllm-wasm`, `await init()`, and
call `runAgent` with a host that has no `command` kinds (or supplies its own).
